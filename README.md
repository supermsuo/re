# 智能密码工具箱 v9.0

### 项目简介

一个便捷解密的网页、现代化的密码学工具套件，专为CTF选手、安全研究人员和密码学爱好者设计。采用模块化架构，代码清晰易维护。

### 模块结构
open-re/
├── index.html              # 主页面
├── test_all_functions.html # 功能测试页面
├── README.md               # 项目文档
├── css/
│   ├── style.css           # 主样式
│   └── theme.css           # 主题样式
├── js/
│   ├── core.js             # 核心模块
│   ├── app.js              # 应用初始化
│   ├── ai.js               # AI智能识别模块
│   ├── ctf.js              # CTF解题模块
│   ├── classic.js          # 古典密码模块
│   ├── modern.js           # 现代密码模块
│   ├── encode.js           # 编码转换模块
│   ├── hash.js             # 哈希算法模块
│   ├── crypto.js           # 加密算法模块
│   ├── network.js          # 网络工具模块
│   ├── stego.js            # 隐写分析模块
│   ├── ui.js               # UI交互模块
│   └── utils.js            # 实用工具模块
└── libs/                   # 第三方库目录
